# USTC_Automation
中国科学技术大学自动化专业课程资料整理仓库，主要收录从大一到大三的部分学习资料，按学期和课程分类。

仓库内容以个人整理为主，包含但不限于：
- 课程笔记
- 课本与课本答案
- 作业与作业答案
- 复习资料
- 历年试卷与真题
- 部分实验代码与实验报告

## 常见资料分类

各课程目录下的子文件夹命名基本遵循资料用途，例如：

- `笔记`：课堂笔记、整理笔记、手写笔记
- `课本`：教材或教材扫描版
- `课本答案`：教材习题答案
- `作业` / `作业答案`：平时作业及参考答案
- `复习` / `复习讲义`：期中期末复习资料、知识点总结
- `试卷` / `试卷及答案`：历年试卷、样卷、参考答案
- `往年题` / `考研真题`：课程相关真题、考研真题整理
- `实验代码` / `实验报告`：实验项目代码与报告材料

## 使用建议

- 优先按学期和课程查找资料，再进入对应子目录定位具体内容。
- PDF、图片、源码等文件混合存放时，通常会围绕同一门课的复习或实验主题组织。
